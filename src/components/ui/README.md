# `components/ui` — the design system

**One responsibility:** visual building blocks that match `Design files/Prioritizing project scope/00 Design System.dc.html`. No data fetching, no business rules, no scoring.

See every component live, in every state, at **`/dev/components`**.

## Two kinds of file live here

| Kind | Files | Source |
|---|---|---|
| **Design-system specific** — no shadcn equivalent | `status-pill`, `difficulty-badge`, `banner`, `empty-state`, `stat-card`, `band-score`, `accuracy-bars`, `band-trend-chart`, `student-tab-bar`, `staff-sidebar`, `pin-input` | Hand-built from the design file (M0-02) |
| **Generic primitives** | `button`, `input`, `card`, `checkbox`, `table`, `dialog`, `select`, `sonner`, `skeleton`, `badge`, `label` | shadcn/ui, restyled to the tokens (M0-03) |
| **Small additions** | `filter-chip` | Hand-built (M0-03) — a toggle, not a label, so not a Badge |

Custom files are named so they **can't collide with shadcn's**: it ships `sidebar`, `chart` and `alert`, so ours are `staff-sidebar`, `band-trend-chart` and `banner`. Keep it that way.

## Rules

- **Tokens only.** Use `bg-brand`, `text-ink-2`, `border-line`, `rounded-card`, `text-body`, `h-primary`. The default Tailwind palette and type scale are switched off in `src/app/globals.css`, so `bg-blue-500` or `text-sm` silently generate nothing.
- **Merge classes with `cn()`** from `@/lib/utils`, never string concatenation. Plain `twMerge` drops `text-body` when combined with `text-ink`; ours is configured not to.
- **Colour never carries meaning alone.** Pair it with a glyph (✓ ✕ ! ○) and a word.
- **Student text is never below `text-body` (16px).** `text-small` is for admin/teacher screens and captions.
- **Student tap targets ≥ 48px** (`min-h-touch`); primary actions are 56px (`h-primary`).
- **Cards get a 1px border, never a shadow.** `shadow-soft` is for modals, dropdowns and sticky bars only.
- **TSDoc on every export.** Say what it's for and any rule it enforces.

## The shadcn primitives are ours now

They were generated by `npx shadcn@latest add …` and then rewritten against the tokens. **Don't re-run `shadcn add --overwrite` on them** — it restores shadcn's defaults (grey palette, 36px buttons, shadowed cards) and throws away the restyle. To add a *new* primitive, `add` it, then restyle it the same way before using it.

What changed from shadcn's defaults, and why:

| Component | API | Rule it enforces |
|---|---|---|
| `Button` | `variant`: `primary` · `secondary` · `ghost` · `danger` · `inverse` · `inverse-secondary`. `size`: `student` (56) · `modal` (48) · `admin` (40, default). `loading`. | Sizes are named for **audiences**: the height is a usability decision. `loading` keeps the button's colour and width; it does not turn grey. |
| `Input` / `PhoneInput` | `size`: `student` (56, default) · `admin` (40). `numeric`. Error via `aria-invalid`. | 16px text always — iOS zooms the page on focus below that. `+91` is fixed, not editable. |
| `Card` | — | 1px `border-line`, **no shadow**. shadcn's `shadow-sm` was removed on purpose. |
| `Dialog` / `ConfirmDialog` | `ConfirmDialog destructive` | The destructive choice is the **secondary**-styled button; the safe one is primary. |
| `Table` + `TableCard`, `TableToolbar`, `TablePagination`, `TableBulkActions` | `TableRow selected`, `TableHead sorted`, `TableHeader sticky` | `aria-sort` and `aria-selected` are set from the props, so state is announced, not just drawn. The bulk bar always states its row count. |
| `Checkbox` | `checked="indeterminate"` | Draws a dash. shadcn draws a tick for both — "all selected" when only some are. |
| `Toaster` | mounted once in `layout.tsx`; call `toast.success(…)` | Always dark, bottom-centre above the tab bar. No `next-themes`. |
| `Skeleton` | — | Uses the `skeleton-shimmer` utility; never a spinner. |

### Three traps when editing these files

1. **No `outline-none` on a control.** In Tailwind v4 it is `outline-style: none` in the *utilities* layer, which beats the global `:focus-visible` ring in the *base* layer — the keyboard focus ring silently disappears. Let the global rule draw it.
2. **Every `border` needs a colour** (`border-line`). v4's default border colour is `currentColor`, so a bare `border` draws near-black.
3. **shadcn's semantic classes** (`bg-primary`, `text-muted-foreground`, `border-input` …) resolve through an alias layer in `globals.css` so vendored internals stay visible. Don't write them in new code — use the token names.
