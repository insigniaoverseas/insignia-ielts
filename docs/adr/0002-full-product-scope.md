# ADR 0002: Scope: the full product, student + teacher + admin

- **Status:** Accepted
- **Date:** 2026-09-14
- **Origin:** `MVP-1.md` §3 D2

## Context

The source plans describe phases 0–3 plus analytics. Shipping only the student side would leave staff running batches from spreadsheets.

## Decision

MVP-1 covers **all three roles** — students (take tests, see results), teachers and invigilators (assign, monitor, release, analyse) and admins (students, plans, batches, tests, staff, audit).

## Consequences

- Milestones M0–M10 in `PROJECT-MEMORY.md` §2 track all three.
- Writing and Speaking are out of scope; `tests.skill` already has room for them.
